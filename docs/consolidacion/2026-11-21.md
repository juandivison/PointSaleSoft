## Repetir las pruebas locales

Requisitos: Windows, SDK .NET 10, Delphi 7 e IBX, Firebird local y credencial local
en el módulo de conexión. No subir esa credencial ni bases, XML, logs o respaldos.

1. Restaurar/compilar PointSaleSoft.Sync/tests/PointSaleSoft.Sync.Tests.csproj en Release.
2. Ejecutar qa/Restaurar-Timbre-Ventas/Verificar.ps1.
3. Ejecutar qa/Inventario-Codigo-Grupo/Verificar.ps1.
4. Ejecutar qa/Regresion-Gastos-Normal/Verificar.ps1.

PSS_DCC32 permite indicar el compilador; PSS_FIREBIRD_PROVIDER indica la biblioteca
del proveedor si no se usa la compilación Release de Sync. La prueba de gastos
requiere bibliotecas del motor ya compiladas: PSS_IDESI_RUNTIME permite indicar
su carpeta, sin construir ni cambiar ese proyecto. Los datos de QA se generan en
Build y no se versionan. Las pruebas Sync de datos requieren sus copias QA bajo
artifacts, que tampoco se versionan. Nunca ejecutar sobre una base comercial.
